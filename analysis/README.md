# Synthetic Trip Analysis

This directory contains a reproducible analysis of the public synthetic replay dataset. The data is generated by `scripts/generate_synthetic_data.py` and does not contain captured vehicle identifiers or private historical data.

## Run

```bash
python analysis/synthetic_trip_analysis.py
```

Generated outputs:

- `results/synthetic_analysis_summary.json`
- `results/complete_synthetic_trips.csv`
- `results/incomplete_synthetic_trips.csv`
- `figures/synthetic_observations_per_5_minutes.png`
- `figures/synthetic_complete_trip_durations.png`

The analysis deliberately includes two incomplete trips and excludes them from the complete-trip summary. This demonstrates explicit completeness criteria and transparent handling of partial records.
